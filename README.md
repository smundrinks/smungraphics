# Graphic Designer Portfolio

A modern, responsive portfolio website for a graphic designer.

## Features
- Responsive layout
- Hero section
- About section
- Services
- Portfolio/project showcase
- Design process
- Contact form UI
- Mobile navigation
- No framework required

## Run locally
Open `index.html` in your browser.

## Customize
1. Change `Alex Studio` and the text in `index.html`.
2. Replace the project concept blocks with your own images.
3. Update colors and typography in `style.css`.
4. Connect the contact form to a form service or backend.

## GitHub Pages
Upload the files to a GitHub repository, then open:
**Settings → Pages → Deploy from a branch → main → / (root)**

Your portfolio can then be published with GitHub Pages.
